The problem

Clients do not return

Growth is a feeling

Was Tuesday empty because of weather, price, or the wrong hours? Spreadsheets lie; chat logs do not add up.

AI manager

The assistant reads schedule, CRM, and metrics — never raw names or phones. It proposes drafts (book, move, cancel, message). You confirm. Booking Engine validates every change the same way the calendar does. Nothing applies silently.

Smart booking

Three decisions: service → specialist (filtered by who actually offers it) → a free slot. Phone with country code. Confirmed or pending, honestly. Add to calendar (.ics) and a private link. No client account, no OTP.

Clients come back

Every public booking creates a CRM profile (E.164 phone). Trust is NEW / HIGH / NORMAL / LOW with reasons, not a mystery score. Reminders go through Telegram when linked; otherwise a ready-to-send task lands on your dashboard.

Growth on metrics

Slot utilization

Booked service minutes / available minutes.

Repeat rate

Clients with two completed visits / clients with one.

Return interval

Median of each client’s median gap.

No-show rate

No-shows / visits that reached start time.

Value per hour

Completed service value / hours actually worked.

Churn risk

Rule-based: last visit vs 1.5× / 2× personal interval.
